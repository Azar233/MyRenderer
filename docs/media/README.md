# Portfolio media

- `prism5_demo_reel.mp4`: deterministic 360-frame Prism-5 parameter animation,
  encoded at 24 fps for a 15-second 1280 × 720 portfolio preview.

The source PNG sequence is generated in the build directory and intentionally
not versioned. Recreate and encode it with the commands in
`docs/prism5-validation.md`.
